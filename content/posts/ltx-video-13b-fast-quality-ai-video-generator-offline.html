📍 How to Use LTX Video 13B

Getting started with LTX Video is straightforward. Here’s a step-by-step guide on how to use it effectively.

1. Accessing LTX Studio

For those who prefer an online option without the need for a GPU, LTX Studio is a great place to start. You can sign up for a free account and explore various features like storyboarding and image generation.

2. Generating Your First Video

To generate a video using LTX Video, follow these steps:

  1. Navigate to the motion generator section.
  2. Select the latest 13B model.
  3. Upload an image to use as a starting frame.
  4. Input a prompt describing your desired scene. For example, “intense boxing match high action.”
  5. Set the duration and motion intensity.
  6. Click on “generate video.”

Once you click generate, the tool outputs four videos simultaneously, showcasing its speed and efficiency.

🔧 Installing LTX Video Locally

For those interested in running LTX Video locally, the installation process is relatively simple. Below is a streamlined guide:

1. Setting Up Comfy UI

Before installing LTX Video, ensure you have Comfy UI installed. This interface simplifies the integration of various video generation models.

2. Downloading the LTX Video Model

Navigate to the official repository and download the 13B version. There are two options: a full version requiring high VRAM and a quantized version suitable for consumer-grade GPUs.

3. Configuring the Workflow

Once the model is downloaded, you can drag and drop the workflow file onto Comfy UI's canvas. Follow the prompts to install any missing nodes, ensuring a smooth setup process.

4. Generating Videos Locally

After configuring, you can begin generating videos locally. Adjust settings for frame rate, dimensions, and prompts to customize your outputs. Remember, saving your output requires specific actions to ensure your videos are stored correctly.
