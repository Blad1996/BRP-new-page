Claude Is Merging Chat and CoWork

One of the most useful Claude updates is also one of the simplest. Claude and CoWork are beginning to merge into a more seamless experience.

Previously, there was a clear toggle between a standard Claude chat and CoWork. That created a small but real problem: many people did not know which mode they were supposed to use for a particular task.

Instead of making people figure that out themselves, Claude is moving toward making the decision for them. Claude will indicate whether a task should happen in a normal chat or inside CoWork, then ask for approval before proceeding.

That is a good direction. AI tools get more powerful every week, but power means nothing if the product becomes confusing. Reducing decisions at the beginning of a task makes the experience easier and faster.

More Control Over Connectors, Research, Web Search, and Memory

Claude is also making it much easier to control which capabilities are active in a conversation. From the plus menu inside a chat, it is possible to manage:

  • Connectors that allow Claude to interact with connected services
  • Research for deeper information gathering
  • Web search for retrieving current information
  • Memory for retaining relevant context

Each option can be switched on or off for a specific chat. In most cases, keeping these capabilities enabled will make Claude more useful. But having the option matters, especially when handling a task that requires tighter control over privacy, context, or outside information.

This is the kind of update that makes an AI assistant feel more practical. You are not locked into one behaviour. You can decide whether Claude should remember context, browse the web, conduct research, or use a connected application.

Claude Docs, Slides, and Design Turn Work Into an Editable AI Workspace

CoWork now goes much further than chat responses. Claude can produce work in dedicated formats for documents, slide decks, and design.

This means you can give Claude a source file, a launch kit, a set of notes, or project information and ask it to create something usable from it. Rather than receiving only a block of text, you can receive a structured asset that can be edited, redesigned, shared, and exported.

Turning a Launch Kit Into a Slide Deck

For example, you can upload a zip file containing launch materials and ask Claude to evaluate launch readiness and turn the findings into a presentation. Claude can create the slide deck, organize the content, and give you the ability to edit the output directly.

You can then change colours, layouts, themes, and design choices. You can also use an existing design system so that the deck looks closer to the brand or style you want.

The more interesting part is what happens after the deck exists. You can leave a comment telling Claude to use a certain slide design, then ask it to create related assets such as PowerPoint mockups, social images, and standard social-media sizes.

That is a huge shift. Instead of creating a presentation in one tool and then rebuilding its visuals in another, you can keep the work moving inside the same AI-enabled environment.

Claude Docs Can Research, Write, Format, and Export

Claude Docs is equally impressive. You can ask Claude to create a document on a specific topic, such as a roundup of recent Claude updates for a school community. From there, it can research the topic, identify useful connectors, show its progress, and create a formatted document.

The output is not just raw writing. It can include:

  • Tables
  • Tabs
  • Images
  • Checklists
  • Links to relevant announcements
  • Structured sections and categories

If you want revisions, Claude can edit the existing file instead of producing a completely new version. That matters because one of the most annoying parts of using AI is version sprawl. You ask for a change, then suddenly have five documents instead of one polished document.

When the document is ready, it can be shared by email or link, with access controls for collaborators. It can also be exported as a Word document, PDF, Markdown file, Google Doc, or Notion page.

Honestly, this starts to look like Claude is coming after the territory traditionally owned by Google and Microsoft. It is not just helping create work. It is becoming the environment where the work gets produced, formatted, and distributed.

Claude Design, Docs, and Slides Are Also Available in Claude Code

These new formats are also extending into Claude Code. You can ask Claude Code for a design review deck or a UI mockup, point it toward relevant files or an RFC in a repository, and have it create the output.

The finished result can remain inside the conversation for review or be edited and shared through a generated link. For product teams and developers, that could make it much easier to turn technical documentation into useful visual and presentation-ready work.

Claude for Small Business Connects AI to More Than 9,000 Tools

The biggest Claude update here is the Claude for Small Business connector. This combines Claude with Zapier, giving Claude access to a huge layer of connectivity across more than 9,000 apps.

That is where things get absolutely nuts.

Claude can already reason through tasks, generate content, and organize information. Zapier gives it access to the tools where real business activity happens: inboxes, CRMs, payment systems, bookkeeping apps, marketing platforms, calendars, and much more.

Together, they create a system that can help automate business operations instead of simply giving advice about how to automate them.

You can get started through the Claude for Small Business connector.

How the Zapier Connector Works

After connecting Zapier to Claude and granting permission, Claude can access available Zapier skills and identify the apps already connected to your Zapier account.

It can show what each connected service can read, what it can write, and which tasks it can automate. The core idea is simple: Claude becomes the intelligence layer, while Zapier becomes the connectivity layer.

The setup includes prebuilt skills for common business tasks, with dozens of ready-made options available. Those skills cover areas such as:

  • Lead outreach and follow-up
  • Inbox organization
  • Business reporting
  • Onboarding workflows
  • Agent creation
  • Operational tasks
  • Books, payments, and pipeline reporting

You can also create your own skills and describe the automation you want in plain English. That is the real opportunity here. The barrier is getting lower. You do not necessarily need to build a complicated workflow manually before Claude can begin helping.

Examples of Claude for Small Business Automation

One useful example is an outreach skill connected to a CRM. Claude can help follow up with leads by using the information already inside that system.

Another is a business pulse skill. This can be used to generate reports around important areas of the business, including financials, payments, and sales pipeline activity.

Then there is the inbox workflow, which might be the most immediately useful for a lot of people. You can ask Claude to review what arrived in your inbox over the previous 24 hours, summarize what needs attention, draft replies in your voice, and label messages that are ready for review.

That task can also be turned into a scheduled automation that runs every morning. Instead of digging through an overloaded inbox, you can begin with a clear breakdown of:

  • What needs attention
  • Which drafts are ready
  • Important money and account updates
  • Business signals
  • Product and ecosystem news

This is barely scratching the surface. Any repeatable work process that touches apps available through Zapier could potentially be brought into Claude CoWork and automated.

That is why this matters so much for small businesses. Busywork is not just annoying. It consumes the time needed for sales, customer relationships, product development, and actual decision-making.

Claude Code Projects Can Run Work in Parallel

Claude is also rolling out projects within Claude Code on desktop and web. A project functions as an ongoing body of work that Claude can split into multiple threads.

Claude can run those threads as parallel cloud sessions, transfer context between them, and keep working even after you leave the session.

Instead of treating every request as a completely separate chat, projects make it possible to organize complex work into a more connected workflow. That is important when a task has multiple pieces that can be completed at the same time.

For anyone dealing with larger research, coding, operations, or content projects, parallel work could save a lot of time.

ChatGPT Now Supports Chrome Extensions

ChatGPT is getting some major updates too, starting with Chrome extension support inside its desktop browser experience.

Imagine asking ChatGPT to handle something involving an account login, such as reviewing or renewing pet insurance. ChatGPT can navigate to the relevant sign-in page, but it does not need you to type your password into the chat.

Instead, it can use a browser extension such as 1Password to autofill the login details. That is a meaningful improvement because credentials can stay within the password-manager flow rather than being directly shared with the AI.

This makes automation more practical for tasks that normally get stuck at the login screen. It also shows where AI agents are heading: not merely recommending actions, but interacting with the same browser tools people already rely on.

OpenAI for Law and GPT 6 Astra Law

OpenAI has also introduced a legal-focused model called GPT 6 Astra Law, powered by Astra 6. This is positioned as a purpose-built AI system for lawyers and law firms.

Legal work involves a massive amount of drafting, document review, precedent research, checklist management, and preparation. The goal of a specialized legal AI model is to accelerate those repetitive, time-heavy processes.

For example, the system can be asked to draft an S-1 shell mapping for a specific company after receiving the relevant company fact sheet. It can ask follow-up questions when needed and produce a completed output rapidly.

In the demonstrated example, the task was completed in 26 seconds, work that could otherwise take a person at a law firm much longer.

The legal system also includes direct connections to legal tools and a collection of skills focused on common legal workflows, including:

  • Closing checklists
  • Precedent searches
  • Deposition preparation
  • Contract-related work

It also includes automated safeguards and zero data retention, designed to keep legal data private. The implications are massive. Legal professionals could automate a significant portion of routine work and spend more of their time on judgment, strategy, negotiation, and client relationships.

ChatGPT Plugins Can Now Connect Multiple Accounts

Another practical ChatGPT upgrade is multi-account support across plugins. Instead of connecting only one account to a plugin such as a calendar, you can connect multiple accounts.

That means personal and business accounts can coexist in the same ChatGPT setup. You no longer need to constantly disconnect and reconnect accounts or maintain separate ChatGPT accounts just to access different calendars, services, or data sources.

It is a smaller update than legal AI or browser extension support, but it solves an extremely common productivity problem.

ChatGPT Is Coming to Microsoft Word

While Claude appears to be building more of its own workspace, ChatGPT is embedding itself into existing tools. Microsoft Word is a major example.

Inside Word, ChatGPT can provide access to ChatGPT 6 Astra and support file uploads, custom skills, app connections, and custom instructions. This opens the door to automating document work directly where it already happens.

For example, you could create a contract review skill that identifies unresolved risks and decisions in a contract. The AI can inspect the document, run the skill, and highlight items that need attention.

That can help with:

  • Editing and rewriting
  • Formatting
  • Document creation
  • Contract review
  • Issue identification
  • Connected workflows across apps

Claude is trying to make the AI workspace itself more complete. ChatGPT is trying to insert powerful AI into the tools people already use every day. Both approaches are worth paying attention to.

The Bigger Shift: AI Is Moving From Chat to Action

The real story is not any single feature. It is that AI is shifting from being a chatbot to becoming an operational layer for work.

Claude can create assets, research topics, manage projects, connect to thousands of apps, and automate recurring business processes. ChatGPT can use browser extensions, work across multiple plugin accounts, assist legal workflows, and operate inside Microsoft Word.

The people and businesses that learn to use these tools early will have a serious advantage. They will spend less time doing repetitive admin work and more time on the work that actually requires human thinking.

If your daily tasks involve inbox management, lead follow-up, reporting, documents, presentations, design assets, contracts, or connected apps, there is a very good chance AI automation can now help.

The move is simple: identify one repeated task that wastes time every week, connect the relevant tools, and test whether Claude or ChatGPT can take the first pass. You do not need to automate everything overnight. But you do need to start adapting, because these capabilities are moving incredibly fast.
