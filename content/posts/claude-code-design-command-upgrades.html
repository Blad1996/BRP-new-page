Claude AI and Claude Code just received a stack of upgrades that can seriously change how you design, code, automate work, manage knowledge, and run tasks from your phone. The biggest changes include the new /design command in Claude Code, a redesigned Claude Design workspace, Gmail and Google Drive connectors, better memory management, Claude Academy, and mobile access to CoWork.

These are not minor interface tweaks. Claude is becoming much more connected to the way real work actually happens. It can move from a design concept to code, pull context from your tools, help draft emails, manage files, and handle recurring workflows with more control over permissions.

The opportunity is huge, but only if you set it up correctly. Here is what changed and how to get the most out of Claude AI and Claude Code.

1. Claude Code Now Has a /design Command

The most exciting update is the beta preview of /design inside Claude Code. You can now ask Claude Code to create an editable design canvas directly from your code environment.

The basic workflow is simple. Type /design, then describe what you want Claude to make. For example, you could ask it to redesign a composer based on the features people use most often. Because Claude Code can access and understand your codebase, this can be much more useful than generating a disconnected mockup from scratch.

Instead of getting a random design concept with no relationship to the product, you can create designs that reflect your app's existing features, flows, and potentially the analytics already built into the product.

Use the Right Permission Mode First

There is one important catch. The /design command does not work in Auto mode. To use it, switch Claude Code into Accept Edits mode.

Claude Code offers several modes that determine how it handles actions and permissions:

  • Auto: Claude handles many permission decisions automatically while checking for risky actions and prompt injection concerns.
  • Manual: You take a more hands-on approach to permissions and actions.
  • Accept Edits: Claude can make edits, and this is the mode needed for the new /design experience.
  • Plan: Claude focuses on planning work before making changes.
  • Bypass Permissions: A higher-control mode that should be approached carefully.

Once Accept Edits is selected, type your design request and be specific about the outcome. Claude can generate multiple design directions, and you can keep refining the one that is closest to what you need.

Do Not Use It Only for Random Concepts

I would not treat this feature as a replacement for open-ended visual brainstorming. Claude Design is better suited for starting fresh and exploring standalone concepts.

The real advantage of Claude Code /design is using it to improve an existing product based on how people actually use it. If your application has analytics, feature usage data, or clear patterns embedded in the codebase, Claude has a much better starting point for making practical design recommendations.

That means prompts like these are far more valuable:

  • Redesign this dashboard around the workflows users complete most often.
  • Simplify the onboarding flow based on the existing account-creation steps.
  • Create a cleaner mobile layout for the highest-traffic features.
  • Improve this settings page so the most important actions are easier to find.

Also, use Opus when working on more complex design tasks. And expect a back-and-forth process. The best output will come from giving feedback, narrowing the direction, and iterating instead of expecting perfection in one command.

2. Claude Design Has a Completely New Workspace

Claude Design has also received a major visual update. The core creation options are still there, but the experience looks completely different and feels much more like a flexible creative workspace.

You can still start from a blank canvas or generate different types of work, including:

  • Mobile app designs
  • Slides and documents
  • Wireframes and UI mockups
  • Animations and 3D objects
  • Resumes and HTML emails
  • Colour and type pairings
  • Research materials
  • Diagrams and flyers

The big difference is not just what Claude Design can create. It is how much more usable the output has become.

From a Simple Prompt to an Editable Diagram

For example, you can ask Claude Design to create a diagram explaining how a soybean farm works. With very little direction, it can produce a structured visual that includes a calendar and a crop flow, giving the information a clear, organized layout.

That is powerful because it turns a broad topic into something immediately editable and presentable. Once Claude creates the asset, you can:

  • Edit the design directly
  • Change individual elements
  • Add comments for collaboration
  • Present in full-screen mode
  • Open the work in a new tab
  • Share or export the result

Claude Design also supports voice interaction, which can make the refinement process faster when you want to describe changes naturally instead of typing every detail.

Connectors, Design Systems, and Skills

The redesigned workspace also supports connectors, design systems, and skills. This matters because design work gets far better when the AI can work with the tools, assets, and standards that are already part of your workflow.

A design system can help keep generated assets closer to an existing brand or product style. Connectors can bring outside context into the process. Skills can make the workspace more repeatable for specific types of tasks.

The output is also highly portable. You can download designs as a PDF, project file, HTML, PowerPoint, and other formats. You can even turn an asset into a video.

3. Send a Claude Design to Claude Code and Build It

This is where things start getting crazy. If you create a design for a mobile app or website in Claude Design, you can send it to Claude Code and have Claude help code it.

That design-to-code connection can dramatically reduce the gap between an idea and a working implementation. Rather than creating a mockup in one tool, manually explaining it to a developer, and then translating it into code, you can use Claude to carry the context forward.

It does not mean you should blindly ship generated code. You still need to review the implementation, validate the experience, and make sure it works properly within your application. But it can remove a lot of blank-page friction and speed up early development.

This is especially useful for:

  • Landing pages and marketing sections
  • New dashboard layouts
  • Mobile app screens
  • Internal tools and prototypes
  • Feature redesigns based on existing product behavior

4. Claude Can Now Work With Gmail and Google Drive

Claude can now connect with Gmail and Google Drive, letting it help manage email threads and files without constantly bouncing between tabs. This capability arrived shortly after ChatGPT introduced similar functionality, and it is a major move toward making Claude more useful for day-to-day operations.

After connecting Gmail or Google Drive through the connectors menu, you can ask Claude to do things like:

  • Find the most recent email you received
  • Search for a specific thread
  • Summarize messages and identify the key context
  • Draft a response with a specific tone or level of commitment
  • Open the draft in Gmail and send it
  • Search and manage files in Google Drive

For example, instead of finding an email manually, reading it, and figuring out what to say, you can ask Claude to locate the latest message and draft a response. Claude can offer several possible reply directions, such as an honest low-commitment response or an option that leaves the door open for future discussion.

You can control whether actions require your approval. That control is important. Email and file access are incredibly useful connectors, but they also touch sensitive information and external communications. Use the approval settings intentionally.

6. Clean Up Claude Memory Every Week

Claude memory can be extremely useful, but bad memory is worse than no memory. If Claude retains outdated details about your priorities, role, preferences, or projects, those small errors can compound over time.

Think of it like plaque on your teeth. It may not feel like a major issue on day one. But let inaccurate information keep building for months, and eventually it can create a massive problem in the quality of Claude's responses.

A Simple Weekly Claude Memory Audit

The best process is to check your memory at least once a week:

  1. Open Customize in Claude.
  2. Go to Capabilities.
  3. Open the memory section and copy what Claude currently remembers.
  4. Paste that information into a new Claude conversation.
  5. Ask Claude to quiz you on whether the memory is still accurate.
  6. Use the quiz or flashcard format to identify incorrect, outdated, or incomplete information.
  7. Return to memory settings, select Edit, and tell Claude what to remember or forget.

This works because Claude can turn its stored assumptions into a structured review. A quiz forces you to confront the specific claims that may be shaping Claude's recommendations and outputs.

Keeping memory accurate helps Claude stay useful as your work, tools, priorities, and projects evolve.

Claude has officially launched Claude Academy, a learning hub with resources for people exploring AI, getting started with Claude, or rolling Claude out to a team.

The academy covers different parts of the Claude ecosystem, including:

  • Claude for technical work
  • The Claude platform
  • Claude AI use cases
  • Claude CoWork
  • Claude Code

It includes tutorials, courses, and use cases. If you have a team, this is especially important. Giving everyone access to the same training resources can reduce confusion, improve adoption, and help establish better internal AI workflows.

You can also turn the learning materials into your own study system. Ask Claude to create quizzes or flashcards based on the concepts you are learning. That is one of the easiest ways to stay current as the tools change so quickly.

8. Claude CoWork Is Now Available on Mobile

Claude CoWork is now available from mobile devices, making it much easier to stay connected to automated work when you are away from your computer.

If you have scheduled tasks or routines running through Claude Code, you can receive notifications on your phone when those tasks complete. You can also access CoWork through the Claude mobile app.

This matters because automation becomes more useful when it is not tied to one device. A daily routine can run in the morning, notify you when it is done, and give you a practical update without requiring you to sit down at a desktop first.

The new default Auto mode supports this by handling permission prompts automatically for lower-risk actions. Claude checks tools for risky behavior or potential prompt injection concerns before executing actions. If it identifies something risky, it will ask for approval.

That gives you a more practical balance between automation and control. You are not approving every tiny action, but you still have a decision point when something requires more caution.

How to Get More Out of Claude AI Right Now

The best way to use these upgrades is to approach Claude as a connected work system, not just a chatbot.

Start with these actions:

  1. Switch Claude Code to Accept Edits and try /design on an existing product flow.
  2. Use Claude Design to create an editable asset, then explore sending it to Claude Code.
  3. Connect Gmail and Google Drive if those tools are part of your daily workflow.
  4. Review the available connectors and identify the tools that could remove repetitive work.
  5. Audit Claude memory weekly so outdated assumptions do not pile up.
  6. Use Claude Academy to build skill across your team.
  7. Set up CoWork routines and mobile notifications for tasks that need regular follow-up.

Claude is moving quickly toward a world where design, coding, communication, files, and recurring tasks can all work together. The people who get the biggest results will not be the ones using every feature once. They will be the ones building repeatable workflows around the features that matter most to their work.

Explore your existing workflows, connect the tools you use most, and start with one automation that saves time every single week. Then build from there.

Frequently Asked Questions

What is the Claude Code /design command?

The /design command is a beta Claude Code feature that lets you create an editable design canvas from within Claude Code. It can be used to design or redesign product experiences with context from your codebase.

Which Claude Code mode is required for /design?

You need to use Accept Edits mode. The command does not work in Auto mode.

Can Claude connect to Gmail and Google Drive?

Yes. After connecting Gmail and Google Drive through Claude's connectors menu, Claude can search messages, draft replies, help manage files, and open email drafts in Gmail for sending.

How often should Claude memory be reviewed?

A weekly review is a strong habit. Copy Claude's saved memory, ask it to quiz you on the accuracy of that information, then update or remove anything that is no longer correct.

What is Claude Academy?

Claude Academy is Claude's learning resource hub. It offers tutorials, courses, use cases, and guidance across Claude AI, Claude Code, CoWork, technical workflows, and the Claude platform.
